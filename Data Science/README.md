# Software-University AI and Machine Learning Upskill Program

## About the course:

## During this course, participants will develop the right set of knowledge and skills for a successful professional start in the Data Science field. After completing the training, participants will be able to manage the entire process of collecting and processing data: from asking the right questions to publishing the result. They will also possess a developed portfolio that demonstrates this knowledge. 

## During the course, participants will answer practical questions such as:

### • How do you choose the right method for data analysis?
### • How do you apply the scientific method to decision making?
### • How do you use statistical methods to draw conclusions?
### • How is data collected and cleaned to prepare it for analysis and modeling?
### • How is data modeling performed?
### • What is Exploratory data analysis and how is it applied?

## The course concludes with guidelines for building a complete data science application - code architecture and research structure. The training is practically oriented and new concepts will be reinforced with writing code.

## Skills you will acquire:

### Data collection, aggregation and automation

### Data cleaning and preparation for analysis using the scientific method

### Data analysis and visualization techniques

### Working with tabular and unstructured data (images and text)

### Fundamentals of statistical models/machine learning

### Building a comprehensive project: best practices
